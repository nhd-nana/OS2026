## 一、实验要求（来自实验指导书）

**主题**：物理内存和页表

**目标**：

1. 理解**页表的建立和使用**方法
2. 理解**物理内存的管理**方法
3. 理解**页面分配算法**

**整体实现链**：

```
pmm_init() -> init_pmm_manager() -> page_init() -> init_memmap() -> alloc_pages()/free_pages()
```

lab2 的 `entry.S` 已在内核入口打开 Sv39 分页（`csrw satp` + `sfence.vma`），内核从 `0xFFFFFFFFC0200000`（= `0x80200000` + `0xFFFFFFFF40000000`）开始以**虚拟地址**运行；本实验要在这套映射之上建立物理内存管理。

- 成功时正确设置 `va_pa_offset`、`npage`、`pages`，打印探测到的物理内存范围，并完成 `init_memmap()` 注册

> **与指导书的差异（lab1 已踩过，lab2 同样适用）**：
> 材料里 `qemu` / `debug` / `test` 三个 target 仍用 `-device loader,file=...,addr=0x80200000`；仓库里已统一改为 `-kernel $(UCOREIMG)`（两个版本 QEMU 都可用，且会通过 `a1` 传递 DTB 地址）。

## 六、验收标准

### 6.1 自动评分（`make grade`）

`make grade` 流程：`clean` → 复制到 `/tmp/lab2_grade` → `python3 tools/inject.py` 注入 `kern/test/{test_lab2.c,.h}`（并在 `pmm_init()` 末尾插入 `test_page_init(); test_best_fit();`）→ 运行 `tools/grade.sh`（QEMU + gdb 读符号）。

**必须出现两行 PASS**：

```
[Test 1] Page Init: PASS
[Test 2] Best-Fit: PASS
```

`test_page_init()` 的 8 条检查（可直接当实现清单）：

1. `va_pa_offset == PHYSICAL_MEMORY_OFFSET`
2. DTB 报告的 `mem_base / mem_size` 非 0
3. `npage == PPN(mem_base + mem_size)` 且 `npage > nbase`
4. `pages` 非空、页对齐、位于 `ROUNDUP(end, PGSIZE)` 之后
5. `nr_free_pages()` 落在 `(0, npage - nbase]`
6. 内核尾部页 `pa2page(PADDR(end))` 已被 `SetPageReserved`
7. 描述符数组首地址所在页也被 `SetPageReserved`
8. `pa2page(page2pa(q)) == q`（地址转换往返正确）

`test_best_fit()` 检查 `pmm_manager == &best_fit_pmm_manager`（即已注册并切换）。
`best_fit_check()` 内另有 6 个细项（`grading: n / 6 points`）校验分配/释放/合并行为。

## 七、已知的坑（先看再动手）

| 现象 | 原因 | 处理 |
|---|---|---|
| `make` 报 `'free_list' undeclared` / `'nr_free' undeclared` | `best_fit_pmm.c` 是**空框架**，内部状态与管理函数都要自己写 | 正常现象，属任务 2 |
| `make qemu` 只有 OpenSBI banner，无内核输出（lab2） | 用了系统 QEMU 7.0：`entry.S` 在物理地址上开 Sv39，7.0 写 satp 后立即重翻译导致取指 page fault | 用 `~/opt/qemu-4.1.1`（见第五节），并 `export QEMU=...` |
| `make grade` 卡住或无输出 | 依赖 WSL 内 `python3`、`riscv64-unknown-elf-gdb`；grade 用 gdb 读符号表 | 先确认工具链齐全，再单独跑 `tools/grade.sh` 看报错 |
| `page_init` 里混用虚拟/物理地址 | 内核跑在虚拟地址，DTB 给的是物理地址 | 物理 ↔ 虚拟用 `PHYSICAL_MEMORY_OFFSET`；`struct Page *` 是虚拟地址，`page2pa()` 才得物理地址 |
| 描述符数组覆盖内核 | `pages` 放在 `end` 之前 | 必须从 `ROUNDUP(end, PGSIZE)` 之后开始 |
